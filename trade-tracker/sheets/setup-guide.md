# Google スプレッドシート セットアップガイド

## 1. 新規スプレッドシートを作成

1. Googleドライブで「新規」→「Googleスプレッドシート」
2. ファイル名: **「トレード記録」**

## 2. 1行目にヘッダーを入力

| セル | 値 |
|------|-----|
| A1 | 管理ID |
| B1 | 日付 |
| C1 | 講師名 |
| D1 | 勝敗 |
| E1 | 通貨 |
| F1 | 方向 |
| G1 | レート値/指値 |
| H1 | LC予定 |
| I1 | 分割決済 |
| J1 | クローズ価格 |
| K1 | TP予定 |
| L1 | 損益pips |
| M1 | 備考 |

## 3. L2セルに計算式を入力

```
=IF(J2="","",IF(E2="XAU/USD",(J2-G2)*IF(F2="Buy",1,-1)*10,IF(OR(E2="BTC/USD",E2="ETH/USD",E2="NAS100"),(J2-G2)*IF(F2="Buy",1,-1)*0.1,(J2-G2)*IF(F2="Buy",1,-1)*100)))
```

### 計算ロジック

```
IF クローズ価格が空 → 空欄
  ELSE IF ゴールド（XAU/USD）     → (クローズ - エントリー) × 方向係数 × 10
  ELSE IF 仮想通貨・ナスダック    → (クローズ - エントリー) × 方向係数 × 0.1
  ELSE FX通貨ペア                 → (クローズ - エントリー) × 方向係数 × 100
```

| 銘柄 | 係数 | 計算例 |
|------|------|--------|
| FX（USD/JPY等） | × 100 | 0.5円差 → 50pips |
| ゴールド（XAU/USD） | × 10 | 10ドル差 → 100pips |
| 仮想通貨（BTC/USD等） | × 0.1 | 500ドル差 → 50pips |
| ナスダック（NAS100） | × 0.1 | 50ポイント差 → 5pips |

## 4. L2の計算式を L3〜L1000 までコピー

1. L2セルを選択
2. セル右下の ■ をドラッグして L1000 までコピー
3. または L2 をコピー → L3:L1000 を選択 → 貼り付け

## 5. 書式設定（推奨）

| 列 | 書式 |
|----|------|
| A（管理ID） | 数値（整数） |
| B（日付） | テキスト（MM/DD） |
| G（レート値） | 数値（小数点以下適宜） |
| H（LC予定） | 数値（小数点以下適宜） |
| J（クローズ価格） | 数値（小数点以下適宜） |
| K（TP予定） | 数値（小数点以下適宜） |
| L（損益pips） | 数値（小数点以下2桁） |

## 6. データ入力規則（推奨）

| 列 | 規則 |
|----|------|
| C（講師名） | リスト: よっとん, うなぎ, カエデ, 処刑ちゃん, 小鳥, sixamo, ミカサ |
| D（勝敗） | リスト: Wait, Win, Lose, Draw |
| F（方向） | リスト: Buy, Sell |

## 7. 条件付き書式（任意・見やすさ向上）

### D列（勝敗）
| 値 | 背景色 |
|----|--------|
| Win | 緑 |
| Lose | 赤 |
| Draw | 黄 |
| Wait | グレー |

### L列（損益pips）
| 条件 | 文字色 |
|------|--------|
| 正の値 | 緑 |
| 負の値 | 赤 |

## 8. スプレッドシートのURLをメモ

URLの形式: `https://docs.google.com/spreadsheets/d/{SPREADSHEET_ID}/edit`

`{SPREADSHEET_ID}` の部分をMakeとGlideの設定で使用します。
