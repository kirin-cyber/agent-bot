## 結合テストチェックリスト

### エントリーフロー

- [ ] LINEスクショをアップロードできる
- [ ] Claude APIがJSONを正しく返す
- [ ] 確認画面に読み取り結果が表示される
- [ ] 修正してから登録できる
- [ ] Sheetsに新規行が追加される
- [ ] D列が "Wait" になっている
- [ ] 管理IDが発行・表示される

### 決済フロー

- [ ] 未決済リストにD列="Wait"のポジションのみ表示される
- [ ] タップで管理IDが自動セットされる
- [ ] 決済スクショをアップロードできる
- [ ] J列（クローズ価格）が更新される
- [ ] L列の損益pipsが自動計算される

### 勝敗判定

- [ ] is_final=true → L列pips>0 → D列が "Win"
- [ ] is_final=true → L列pips<0 → D列が "Lose"
- [ ] is_final=true → L列pips=0 → D列が "Draw"
- [ ] is_final=false → D列が "Wait" のまま

### 分割決済

- [ ] 部分利確の記載あり → I列に内容が記録される
- [ ] 部分利確の記載なし → I列が空（null）のまま
- [ ] 分割決済中はD列が "Wait" を維持

### 銘柄別損益計算確認

- [ ] FX（USD/JPY等）: 価格差 × 100 が正しい
- [ ] ゴールド（XAU/USD）: 価格差 × 10 が正しい
- [ ] 仮想通貨（BTC/USD等）: 価格差 × 0.1 が正しい
- [ ] ナスダック（NAS100）: 価格差 × 0.1 が正しい
