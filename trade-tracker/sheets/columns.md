# Google スプレッドシート 列構成定義

## 列構成（A〜M列）

| 列 | 項目名 | 入力方法 | 備考 |
|----|--------|----------|------|
| A | 管理ID | 自動（連番） | Make側で採番。未決済リストの選択キー |
| B | 日付 | AI自動 | スクショから読み取り・JST変換。MM/DD形式 |
| C | 講師名 | AI自動 | よっとん / うなぎ / カエデ / 処刑ちゃん / 小鳥 / sixamo / ミカサ |
| D | 勝敗 | 自動 | エントリー時=Wait。最終決済時にWin/Lose/Drawを自動判定 |
| E | 通貨 | AI自動 | XAU/USD、NAS100、BTC/USD等の統一表記 |
| F | 方向 | AI自動 | Buy / Sell |
| G | レート値/指値 | AI自動 | エントリー価格（数値のみ） |
| H | LC予定 | AI自動 | 損切り価格。pips指定の場合はAIが自動計算 |
| I | 分割決済 | AI自動（決済時） | 部分利確の記載がある場合のみ「部分利確50%」等を記録。記載なしはnull |
| J | クローズ価格 | AI自動（決済時） | 部分/最終とも上書き更新。1行で管理 |
| K | TP予定 | AI自動 | テイクプロフィット価格（あれば） |
| L | 損益pips | Sheets関数で自動計算 | J列更新のたびに自動再計算。最終決済後に勝敗判定のトリガー |
| M | 備考 | AI自動 | メッセージ原文 |

## 勝敗判定ルール（D列）

| 条件 | D列の値 | タイミング |
|------|---------|-----------|
| エントリー時 | Wait | エントリーフロー実行時 |
| 分割決済中（I列に値あり） | Wait維持 | 決済フロー実行時（途中） |
| 最終決済・損益pips > 0 | Win | 最終決済フロー実行時 |
| 最終決済・損益pips < 0 | Lose | 最終決済フロー実行時 |
| 最終決済・損益pips = 0 | Draw | 最終決済フロー実行時 |

※ 勝敗判定は `is_final=true` のみをトリガーとする。I列（分割決済）の有無は判定条件に含まない。

## データ入力規則

| 列 | 規則 |
|----|------|
| C（講師名） | リスト: よっとん, うなぎ, カエデ, 処刑ちゃん, 小鳥, sixamo, ミカサ |
| D（勝敗） | リスト: Wait, Win, Lose, Draw |
| F（方向） | リスト: Buy, Sell |

## 書式設定

| 列 | 書式 |
|----|------|
| A（管理ID） | 数値（整数） |
| B（日付） | テキスト（MM/DD） |
| G（レート値） | 数値（小数点以下適宜） |
| H（LC予定） | 数値（小数点以下適宜） |
| J（クローズ価格） | 数値（小数点以下適宜） |
| K（TP予定） | 数値（小数点以下適宜） |
| L（損益pips） | 数値（小数点以下2桁） |
